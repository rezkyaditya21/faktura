# 📑 Faktura - Studio Dokumen Bisnis & Finansial Cerdas

Aplikasi web modern berkecepatan tinggi bertenaga **Rust (Axum + Tokio)** dan Vanilla JavaScript untuk pembuatan faktur profesional, kwitansi tanda terima resmi, surat jalan pengiriman, dan kalkulator finansial UMKM & KPR.

![Faktura Banner](https://raw.githubusercontent.com/rezkyaditya21/faktura/main/static/css/style.css)

## ✨ Fitur Unggulan

- **📑 Generator Dokumen Bisnis:**
  - Faktur Penjualan / Tagihan (Invoice).
  - Kwitansi Tanda Terima Resmi dengan **Konverter Angka ke Terbilang Rupiah Otomatis**.
  - Surat Jalan Pengiriman Barang.
- **✍️ Tanda Tangan Digital:** Goreskan tanda tangan langsung dengan mouse atau layar sentuh (HP/Tablet).
- **🖨️ Cetak & Simpan PDF (A4):** Format tata letak dokumen presisi tinggi standar cetak A4.
- **💰 Kalkulator Finansial:**
  - Pajak Final UMKM PP 23 (Tarif 0,5%).
  - Simulasi Angsuran & Cicilan KPR Bank.
- **⚡ QR Code Studio:** Generator QR code instan untuk URL, Direct Chat WhatsApp, dan WiFi.
- **🔒 Privasi 100% Terjamin (Zero-Database):** Seluruh data diproses secara lokal di peramban (Client-Side), tanpa penyimpanan data keuangan di server.

## 🚀 Menjalankan Secara Lokal

```bash
# Clone repository
git clone https://github.com/rezkyaditya21/faktura.git
cd faktura

# Jalankan server Rust
cargo run
```

Buka peramban di `http://127.0.0.1:3000`.
