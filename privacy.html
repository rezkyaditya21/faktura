Kebijakan Privasi (Privacy Policy)

Terakhir diperbarui: 4 September 2026

Selamat datang di Faktura ("kami", "layanan kami"). Kami sangat menghargai privasi Anda dan berkomitmen penuh untuk melindungi data pribadi serta kerahasiaan informasi bisnis Anda saat menggunakan situs web kami.

1. Keamanan Dokumen & Pemrosesan Klien (Zero-Server Storage)

Faktura dirancang dengan arsitektur privasi terdepan:

  • Semua data faktur, kwitansi, surat jalan, nama pelanggan, nominal uang, logo perusahaan, dan tanda tangan digital Anda diproses 100% di browser lokal Anda (Client-Side).
  • Kami TIDAK PERNAH menyimpan, merekam, mengunggah, atau mentransfer data transaksi bisnis Anda ke server database kami.
  • Saat Anda mencetak atau menyimpan dokumen dalam bentuk PDF, proses konversi dilakukan langsung di perangkat Anda tanpa melalui perantara pihak ketiga.

2. Penggunaan Cookie & Google AdSense

Situs kami dapat menampilkan iklan yang dikelola oleh Google AdSense atau jaringan periklanan pihak ketiga lainnya.

  • Google sebagai vendor pihak ketiga: Menggunakan cookie untuk menayangkan iklan di situs kami berdasarkan kunjungan sebelumnya pengguna ke situs ini atau situs web lain di internet.
  • Cookie DoubleClick DART: Memungkinkan Google dan mitranya menayangkan iklan kepada pengguna kami berdasarkan kunjungan mereka ke situs kami dan/atau situs lain di internet.
  • Pilihan Pengguna (Opt-out): Anda dapat memilih untuk menonaktifkan penggunaan cookie DART untuk periklanan berbasis minat dengan mengunjungi Pengaturan Iklan Google. Anda juga dapat menonaktifkan cookie pihak ketiga melalui pengaturan peramban (browser) masing-masing.

3. Log File & Analitik Web

Seperti kebanyakan situs web standar lainnya, server kami dapat mencatat informasi teknis standar dalam log file saat Anda mengakses halaman, termasuk:

  • Alamat Protokol Internet (IP address) anonim;
  • Jenis peramban (browser) dan sistem operasi;
  • Penyedia Layanan Internet (ISP);
  • Waktu dan tanggal akses, serta halaman rujukan.

Informasi ini tidak dikaitkan dengan data identitas pribadi apa pun dan hanya digunakan semata-mata untuk analisis teknis stabilitas server serta pencegahan serangan siber (DDoS).

4. Tautan Menuju Situs Pihak Ketiga

Layanan kami mungkin menyertakan tautan menuju platform pembayaran atau donasi pihak ketiga (seperti Saweria, Trakteer, atau WhatsApp). Kami tidak memiliki kendali atas kebijakan privasi platform pihak ketiga tersebut. Kami menyarankan Anda untuk meninjau kebijakan privasi masing-masing situs web eksternal yang Anda kunjungi.

5. Persetujuan Anda

Dengan menggunakan situs web kami, Anda dengan ini menyetujui Kebijakan Privasi kami beserta semua ketentuannya.
